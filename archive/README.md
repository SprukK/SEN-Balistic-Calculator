# Archived builds

Versioned builds of the Main app (`RTI-SEN-Ballistic-Calculator-V{x}.html`) from earlier releases, moved here from the repo root in V2.16.6 (review item U-10, owner ruling: archive). Git history is the rollback path; these copies are kept for reference and because six of them are loaded by the regression suite as "previous release" baselines (V1.17.2, V1.22.0, V1.24.1, V1.25.1, V1.29.1, V1.31.0 — see `tests/README.md`).

The current release's versioned build stays in the repo root next to `index.html` (§21.6 deploy set). At each release, move the previous one in here.
